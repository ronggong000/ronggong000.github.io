# Singyu Muk — Academic Website

Static academic website for GitHub Pages.

## Deploy

1. Create a public repository named `ronggong000.github.io`.
2. Add these files to the repository root.
3. In **Settings → Pages**, deploy from the `main` branch and `/ (root)`.

The site will be available at `https://ronggong000.github.io`.

## Before publishing

- Add the exact ICEPT publication title, authors, venue status, and link.
- Replace or expand the ongoing-research description if needed.
- Add Google Scholar and LinkedIn links when available.
- Add public paper/project links only after they are safe to release.
